# Python Boardgame Tracker

This project is a comprehensive exercise that brings together everything I learned during my Python scripting course.  
It allows you to store and manage information about various board games in a Word document.

---

##  How to run the project
The main script to run is `main.py`.  
The `login.py` script is necessary to check the login credentials before accessing the rest of the program.

---

##  Features
- Add new board games  
- Save board game information to a Word file  
- View an overview of all stored board games (menu option 4)  
- Login system to restrict access  
- Clear menu‑based navigation
